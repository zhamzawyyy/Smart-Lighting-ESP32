# 💡 Smart Lighting ESP32

An IoT-based **Smart Lighting System** built with **ESP32**, combining automatic lighting, motion detection, ambient light sensing, voice control, and remote monitoring.

The system can automatically control an LED based on motion and surrounding light conditions, while also providing manual control through a web interface and Blynk.

## 📌 Project Overview

This project is designed to provide an automated and remotely controlled lighting system using an ESP32 microcontroller.

It combines multiple control methods:

* 🚶 Motion detection using an ultrasonic sensor
* 🌞 Ambient light detection using an LDR
* 🎤 Voice / sound control
* 🌐 Web-based control
* 📱 Blynk mobile control
* ☁️ Firebase data synchronization
* 💡 PWM-based LED brightness control
* ⏱️ Automatic light timeout

The system supports both **automatic** and **manual** operation.

## ✨ Features

### 🤖 Automatic Lighting

The ESP32 continuously monitors:

* Distance using an ultrasonic sensor
* Ambient light using an LDR

When motion is detected and the environment is dark, the LED can automatically turn on.

The system also supports automatic shut-off after a configurable period.

### 🌞 LDR Light Detection

The LDR sensor measures the surrounding light level.

A configurable threshold determines whether the environment is considered bright or dark.

```text
LDR Reading
    │
    ├── Bright → Light OFF
    │
    └── Dark
          │
          └── Motion detected → Light ON
```

### 🚶 Motion Detection

An ultrasonic sensor is used to detect nearby movement.

Current configuration includes:

* Motion ON distance: **25 cm**
* Motion OFF distance: **40 cm**
* Automatic timeout: **30 seconds**

These values can be adjusted in the ESP32 code.

### 🎤 Voice Control

The system supports voice/sound-based control using a microphone module.

Voice activity can be detected locally, while voice commands can also be integrated through Firebase.

The system includes timing and signal thresholds to reduce accidental triggers.

### 🌐 Web Control

A modern web interface allows the user to control the light remotely.

Available controls include:

* Power ON
* Power OFF
* 100% brightness
* 50% brightness
* 30% brightness
* Auto Mode ON/OFF
* ESP32 IP address configuration
* Voice control

### 📱 Blynk Control

The project integrates with **Blynk** for remote monitoring and control.

Blynk can be used for:

* LED state
* Brightness percentage
* Distance readings
* Manual control
* Auto mode
* Brightness presets
* Motion alerts

### ☁️ Firebase Integration

Firebase Realtime Database is used to synchronize system information and commands.

The ESP32 can send information such as:

* Distance
* Light level
* LED state

Firebase can also be used to receive voice-control commands generated by an external application.

## 💡 LED Brightness Control

The LED brightness is controlled using PWM with an **8-bit resolution**, providing values from:

```text
0 ─────────────── 255
OFF                100%
```

Example brightness levels used by the web interface:

| Level | PWM |
| ----- | --: |
| OFF   |   0 |
| 30%   |  77 |
| 50%   | 128 |
| 100%  | 255 |

## 🚀 Getting Started

### 1. Install Arduino IDE

Install the Arduino IDE and add ESP32 board support.

### 2. Install Required Libraries

The project uses libraries including:

```text
WiFi
WebServer
HTTPClient
ArduinoJson
BlynkSimpleEsp32
```

### 3. Configure Wi-Fi

Update the Wi-Fi configuration in the ESP32 source code:

```cpp
#define WIFI_SSID "YOUR_WIFI_NAME"
#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"
```

### 4. Configure Firebase

Add your Firebase Realtime Database configuration using your own credentials.

### 5. Configure Blynk

Add your own Blynk Template ID, Template Name, and Auth Token.

### 6. Connect the Hardware

Connect the ESP32 and sensors according to the pin configuration above.

### 7. Upload the Code

Open the main `.ino` file in Arduino IDE and upload it to the ESP32.

### 8. Access the Web Interface

After connecting to Wi-Fi, check the ESP32 IP address through the Serial Monitor.

Open the IP address in a browser:

```text
http://ESP32_IP_ADDRESS
```

The Smart Control interface will then be available.

## 🔐 Security Note

**Do not upload real Wi-Fi passwords, Blynk authentication tokens, or Firebase credentials to a public GitHub repository.**

Before publishing this project, replace credentials with placeholders such as:

```cpp
#define WIFI_SSID "YOUR_WIFI_NAME"
#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"

#define BLYNK_AUTH_TOKEN "YOUR_BLYNK_TOKEN"

#define FIREBASE_HOST "YOUR_FIREBASE_HOST"
```

If real credentials have already been committed to GitHub, they should be **revoked/rotated** before making the repository public.
